Entry for make.fun's **"Roast the Smart Fridge: One Line, Best Laugh Wins"** bounty — one line roasting a smart fridge (or any smart home gadget it shares a house with), at most 160 characters.

## The line

> My smart fridge photographs my leftovers like a crime scene, rats me out to my watch, and still can't tell a tomato from a ketchup bottle.

## How it works

`main.ts` (Node 22) writes that single line to `/output/entry.txt` — nothing else. The line is 138 characters, inside the 1–160 gate, and the program never deletes `/output` itself, only creates it if missing.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
